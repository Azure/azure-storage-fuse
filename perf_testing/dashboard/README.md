# Blobfuse2 benchmark data

This branch is generated by the Blobfuse2 performance workflow.

- The root GitHub Pages site contains the curated block-cache sustained-throughput results intended for users.
- `/developer/` contains the broader engineering regression dashboard.
- `data/public/history.json` and `data/developer/history.json` contain compact, versioned result histories.
- Raw FIO output, Blobfuse logs, and diagnostic bundles are retained as private ZIPs in the `results` container of the separate benchmark-results Azure Storage account rather than this branch or GitHub Actions artifacts.

Benchmark implementation and operating documentation live on `main` under `perf_testing/`.

The `release/` and issue-metric paths on this branch are independent of performance publication and are intentionally preserved.
